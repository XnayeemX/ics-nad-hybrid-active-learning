# Results

This folder contains the final outputs generated by the complete research-mode
pipeline for the MLP, Random Forest, and XGBoost comparison.

## Experiment Configuration

- Run mode: `research`
- Models: MLP, RandomForest, XGBoost
- Strategies: random, uncertainty, hybrid_open_set
- Seeds: 42, 2026, 31415
- Initial labeled samples per known class: 50
- Active Learning label budget: 300
- Query batch size: 25
- Hidden classes: land, ackpflood, teardrop
- Primary split: `split_A_comparable`
- External split: `split_B_external`

## Final Comparison Files

- `FINAL_paper_ready_hybrid_model_comparison.csv` — compact paper-ready comparison of final Hybrid results.
- `FINAL_hybrid_cross_model_comparison.csv` — detailed Hybrid cross-model comparison.
- `FINAL_hybrid_vs_random_by_model.csv` — Hybrid-versus-Random comparison for each model.
- `FINAL_metric_leaders.csv` — best-performing model for each reported metric.
- `FINAL_target_checklist_all_models.csv` — final target/criterion checklist.
- `FINAL_hybrid_channel_effectiveness.csv` — effectiveness of Hybrid acquisition channels.

## Main Experiment Outputs

- `all_models_final_summary_by_seed.csv` — final per-seed summary.
- `all_models_final_per_class.csv` — per-class performance.
- `all_models_strategy_aggregate.csv` — aggregate performance by model and strategy.
- `all_models_round_metrics.csv` — Active Learning round metrics.
- `all_models_query_log.csv` — query-level Active Learning log.

## External / Version-B Evaluation

- `FINAL_version_B_cross_model.csv` — final cross-model Version-B comparison.
- `version_B_all_models_summary.csv` — Version-B summary across all models.
- `version_B_all_models_per_class.csv` — Version-B per-class results.

## Fairness / Reproducibility Audits

- `fairness_initial_set_audit.csv` — audit of shared initial labeled sets.
- `fairness_random_query_audit.csv` — audit of shared Random Sampling queries.
- `experiment_config.json` — exact configuration used for the final run.
- `preprocessed_feature_names.csv` — transformed feature names after preprocessing.

## Data Limitation
